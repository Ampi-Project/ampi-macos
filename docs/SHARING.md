# Short announcement draft

## Reddit title

I’m building Ampi, a free music player inspired by Winamp

## Reddit post

I miss Winamp’s skins and being able to change the whole player, so I started building Ampi.

The macOS version is still early, but playback, an equalizer, and partial Classic skin support are working. Windows and Linux versions are planned too.

It’s free and open source under GPLv3. Anyone’s welcome to help with code, themes, testing, or ideas.

[GitHub](https://github.com/Ampi-Project/ampi-macos)
